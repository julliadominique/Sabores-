# 🍲 Sabores

> Seu próximo prato favorito a um clique de distância.

O **Sabores** é uma plataforma web desenvolvida para conectar pessoas à arte da culinária de forma simples, intuitiva e rápida. Encontre, salve e compartilhe receitas incríveis para qualquer ocasião.

---

## 🚀 Funcionalidades

- 🔍 **Busca Inteligente:** Pesquise receitas por nome, ingrediente ou categoria.
- ⏱️ **Filtros Rápidos:** Encontre pratos pelo tempo de preparo ou nível de dificuldade.
- ❤️ **Favoritos:** Salve suas receitas preferidas para acessar quando quiser.
- 📝 **Modo Modo de Preparo:** Passo a passo interativo para ajudar na cozinha.
